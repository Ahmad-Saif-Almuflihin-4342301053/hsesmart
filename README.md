# HSE Smart - Aplikasi Audit K3

Aplikasi Audit K3 (Health, Safety, and Environment) berbasis web mobile-first & PWA dengan Next.js App Router, Tailwind CSS, dan Drizzle ORM.

## Tech Stack
- **Framework**: Next.js (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **ORM & Database**: Drizzle ORM (PostgreSQL)
- **Mobile Support**: PWA (Manifest & Standalone Mode)

## Getting Started

Pertama, jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser atau gunakan mode emulasi mobile untuk melihat hasilnya.

## Build

Untuk kompilasi produksi:

```bash
npm run build
```
